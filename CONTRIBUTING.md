# Contributing

Bring a tiny output that has a reason to stay useful. A reproducible recipe and a source change are more valuable than another autonomous-agent slogan.

The runtime uses the Python standard library. Start with `python -m sproutfile demo`, then run `python -m unittest discover -s tests -v`.

For a bug, include your Python/OS version, a minimal manifest, synthetic source data, the command, and the observed result. Never include your grant store, credentials, or private source contents. For a proposal, explain the user-visible capability and the nearest existing project. We want to credit neighbors and learn from them.

Keep recipes declarative, model choice outside the artifact, and file opening inert. Changes to dependency invalidation, publication, path handling, or agent proposals should include a test for the behavior they protect. Please preserve the distinction between source quotation and factual verification.

Small pull requests are welcome. Larger experiments should describe a concrete demo and the behavior when inputs are missing, stale, or contradictory. MIT is the repository license; contributions use the same license.
